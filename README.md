## 买完搬瓦工后应该先做什么

服务器开通后，不建议立即把正式网站全部迁移过去。先做一轮基础检查，能减少后面排查问题的时间。

### 1. 更新系统

首次登录后先更新系统软件包，并删除不需要的默认服务。旧版本软件可能带有已知安全问题，VPS 的 Root 权限也意味着你需要自己负责基础安全。

### 2. 创建普通用户

日常操作尽量不要一直使用 Root。可以创建普通用户，并根据需要配置 `sudo` 权限。这样即使某个网站程序出现问题，也不会让所有系统权限暴露在外。

### 3. 配置 SSH

建议关闭密码登录，改用 SSH 密钥；如果暂时不能关闭密码登录，也应禁止弱密码，并考虑限制 SSH 登录来源。

### 4. 设置防火墙

只开放真正需要的端口。常见网站通常需要 HTTP 和 HTTPS，SSH 端口则应根据你的管理方式保留。数据库端口不应该直接暴露给公网，除非你清楚自己为什么需要这样做。

### 5. 配置备份

VPS 不是自动等于备份。即使服务商提供快照，也不代表你拥有完整、独立、长期可恢复的备份。重要网站至少应保留数据库备份和网站文件备份，并定期测试能否恢复。

### 6. 监控流量和资源

KiwiVM 可以查看使用统计。内存持续接近上限、磁盘快速增长或流量突然异常，往往比网站报错更早暴露问题。早点看到，通常比凌晨收到用户投诉舒服很多。

## 搬瓦工退款、续费和停机规则

官网目前展示 30 天退款政策，但退款并不是无条件自动通过。服务条款要求申请退款的服务属于新订单而非续费订单，订单创建时间不超过 30 天，账户状态正常，IP 未被列入黑名单，并且月度流量使用低于配额的 10% 等。退款后，账户相关服务、数据、快照和备份会被删除。

因此，第一次购买时不要立刻上传唯一副本，也不要在没有备份的情况下进行系统重装。可以先完成：

1. 登录面板。
2. 确认 IP 和 Root 权限正常。
3. 测试 SSH 连接。
4. 检查目标机房和网络是否满足需求。
5. 确认系统和软件能否正常部署。
6. 再开始迁移正式业务。

续费方面，官网知识库说明不会自动扣除信用卡或 PayPal。系统会在续费日期前生成账单；如果账户里有余额，余额可能被用于支付账单。如果没有足够余额，用户需要在账单到期后完成付款，否则服务可能被暂停。

如果不打算继续使用，应在客户区关闭续费，或者及时取消服务。不要把“没有自动扣款”误解为“可以永远不管账单”。账户余额、未支付账单和服务状态仍然需要自己检查。

## 常见问题

### 搬瓦工最便宜的方案是哪一个？

按照官网当前公开页面，20G KVM VPS 的价格为 $49.99/年，是标准方案中入门价格最低的一档。它提供 1 GB 内存、20 GB RAID-10 SSD 和每月 1 TB 流量。

### 1 GB 内存够不够用？

如果只是学习 Linux、部署一个轻量网站或运行低资源服务，1 GB 可以作为起点。如果要同时运行 WordPress、数据库、管理面板、缓存和多个容器，建议考虑 2 GB 或 4 GB 内存。

### 搬瓦工是否适合新手？

适合愿意学习基础服务器操作的新手。购买流程并不复杂，真正需要学习的是开通后的 Linux 管理、安全设置和备份。它不是“完全不用维护”的网站托管服务。

### 可以更换机房吗？

官网介绍 KiwiVM 支持数据中心迁移，但实际能否迁移、可迁移到哪些机房，要以当前服务、库存和账户后台显示为准。迁移前应先做备份，不要把迁移功能当成数据备份方案。

### 需要买最高配置吗？

大多数个人项目不需要。先按当前资源需求购买，等 CPU、内存、磁盘或流量确实不足时再升级，比一开始为不存在的访问量买单更合理。
